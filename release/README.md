## 🔧 Cara Install

1. **Download APK**
   - Download file `anime_verse-1.0.0.apk` dari folder ini

2. **Aktifkan Unknown Sources**
   - Buka **Settings** > **Security** (atau **Apps & Notifications** > **Special App Access**)
   - Aktifkan **"Install Unknown Apps"** atau **"Install from Unknown Sources"**
   - Pilih aplikasi browser/file manager yang akan digunakan untuk install

3. **Install APK**
   - Buka file APK yang sudah didownload
   - Klik **"Install"**
   - Tunggu hingga proses instalasi selesai

4. **Buka Aplikasi**
   - Setelah instalasi selesai, buka aplikasi AnimeVerse dari launcher
   - Login dengan akun yang sudah terdaftar atau buat akun baru

## ⚠️ Catatan Penting

- Pastikan perangkat Android Anda menggunakan **Android 5.0 (API 21) atau lebih tinggi**
- File APK ini sudah di-sign dan aman untuk diinstall
- Jika terjadi masalah saat install, pastikan **Unknown Sources** sudah diaktifkan
- Untuk keamanan, pastikan Anda mendownload APK dari sumber yang terpercaya
